# 月0円から始める、自分専用AI社員3人セット

無料・登録不要・APIキー不要の静的Webページです。

## 使い方

1. `index.html` をブラウザで開く。
2. 調査社員にテーマを入力し、生成された指示文をChatGPTなどに貼り付ける。
3. 調査結果を分析社員に貼り付け、生成された指示文をAIに渡す。
4. 分析結果を発信社員に貼り付け、Xまたはnote用の指示文を生成する。

※このページ自体はAIを実行せず、指示文を生成します。ChatGPTなどのサービスの利用条件・料金は各サービスに従います。

## 公開

GitHubで `ai-staff-free` という新規リポジトリを作成し、このフォルダ内のファイルをリポジトリのルートにアップロードしてください。
VercelでそのリポジトリをImportし、Framework PresetをOther、Build Commandを空欄、Output Directoryを空欄にしてDeployしてください。

## 構成

- `index.html`: アプリ本体
- `vercel.json`: 静的サイト設定

## 参照設計

専門役割の分離・成果物の受け渡しという考え方を参考に独自実装しています。agency-agentsのコードやエージェント定義文はコピーしていません。
